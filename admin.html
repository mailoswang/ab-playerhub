連線到 GitHub

連線後即可讀取並直接發佈網站內容。未連線也能編輯，再用「下載 data.js」手動上傳。

如何取得權杖？
  1. 到 GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
  2. Repository access 選「Only select repositories」，只勾這個網站的 repo。
  3. Permissions → Repository permissions → Contents 設為 Read and write，其他不用開。
  4. 產生後複製 github_pat_ 開頭的字串貼到上面。權杖只會傳給 api.github.com。
共用電腦請不要勾「記住權杖」，關閉分頁後就會清除。
